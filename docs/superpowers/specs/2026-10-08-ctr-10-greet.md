# CTR-10 — `greet` helper and `contrail greet`

**Goal:** a pure `greet(name)` returning `Hello, <name>!`, and a `contrail greet <name>` command that prints it.

## The function

`src/greet.ts`:

```ts
export function greet(name: string): string
```

Returns `` `Hello, ${name}!` ``. Pure: no I/O, no validation, no trimming — the caller owns what it passes. Whatever string goes in comes back inside the template, including an empty one.

## The command

```
contrail greet <name>
```

Prints the result to stdout, exits 0. A missing `<name>` is a usage error: prints `Usage: contrail greet <name>` to stderr and exits 2, matching how `scaffold` and `sheet` already report a missing positional.

**Placement constraint.** `main()` loads `contrail.config.ts` at the point where the config-driven commands begin (`src/cli.ts:566`). `greet` needs no project, so its branch sits above that line, next to `login`/`logout`/`init` — otherwise running it outside a contrail tree throws on a missing config instead of greeting.

`help` gains `greet <name>` in its one-line usage string.

## Boundaries

No name validation, no locale handling, no `--greeting` flag. A greeting is one interpolation; anything more is speculative.

## Acceptance

`npm test` passes, `npm run typecheck` is clean.
