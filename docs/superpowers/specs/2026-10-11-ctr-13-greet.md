# CTR-13 — greet module

**Goal:** `src/greet.ts` exports `greet(name)` returning `Hello, <name>!`, with tests covering a normal name and an empty name.

## Contract

```ts
export function greet(name: string): string
```

Returns `` `Hello, ${name}!` ``. No validation, no trimming, no fallback for an empty string — the empty case is a plain interpolation and is asserted as such.

| Input | Output |
|---|---|
| `'Ada'` | `'Hello, Ada!'` |
| `''` | `'Hello, !'` |

## Where the test lives

`tests/greet.test.ts`, **not** `src/greet.test.ts`.

The ticket text says `src/greet.test.ts`. `vitest.config.ts` says:

```ts
test: { include: ['tests/**/*.test.ts'] }
```

and all existing tests live in `tests/`. A file at `src/greet.test.ts` is collected by nothing and would pass by never running. The config wins; it is not changed. This was flagged at G0 and signed off in the G1 Definition of Ready.

## Constraints

- ESM, TS strict, explicit `.js` extension on the relative import (`../src/greet.js`), matching every other file in `tests/`.
- No semicolons, single quotes — house style, as in `tests/doc-kinds.test.ts`.
- No new dependencies. No existing file is modified.
