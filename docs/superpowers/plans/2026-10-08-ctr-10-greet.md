# CTR-10 — `greet` helper and `contrail greet`

**Spec:** [`docs/superpowers/specs/2026-10-08-ctr-10-greet.md`](../specs/2026-10-08-ctr-10-greet.md)

**Goal:** `greet(name)` returns `Hello, <name>!`; `contrail greet <name>` prints it.

## Global constraints

- ESM, explicit `.js` extensions in imports, TS strict (`noUncheckedIndexedAccess` is on — a positional from `parseArgs` is `string | undefined`).
- Tests are vitest, under `tests/`, importing from `../src/<file>.js`.
- Touch nothing outside `src/greet.ts`, `src/cli.ts`, `tests/greet.test.ts`, `README.md`.

---

### Task 1: the pure function

**Files:** `src/greet.ts`, `tests/greet.test.ts`

```ts
export function greet(name: string): string {
  return `Hello, ${name}!`
}
```

Tests: a plain name gives `Hello, Ada!`; an empty string gives `Hello, !` (the function interpolates, it does not judge).

**Verify:** `npx vitest run tests/greet.test.ts`

---

### Task 2: the `greet` command

**Files:** `src/cli.ts`, `tests/greet.test.ts`, `README.md`

In `main()`, above the `loadConfig(findConfigPath(process.cwd()))` line — the command must work outside a contrail project:

```ts
if (command === 'greet') {
  const name = positionals[1]
  if (!name) {
    console.error('Usage: contrail greet <name>')
    return 2
  }
  console.log(greet(name))
  return 0
}
```

Add `greet <name>` to the `help` usage string.

Tests (same file, a second `describe` block, spying on `console.log`/`console.error` the way `tests/cli.test.ts` already does): `main(['greet', 'Ada'])` logs `Hello, Ada!` and returns 0; `main(['greet'])` returns 2 and writes the usage line to stderr.

README: one line in the Quick start block.

**Verify:** `npm test` and `npm run typecheck`, both clean.
